오늘 할일 · 커스텀 섹션

메모 색상 · 마음대로

⚙ 설정에서 색상 슬라이더로 메모지 색을 바꿉니다. 메모마다 다른 색 탭 — 업무는 노랑, 개인은 파랑처럼 구분해 두세요.

1회성 · 주기적 알람

메모와 별도 알람 보드. 시간이 되면 화면 중앙에 크게 알림. 물 마시기, 병원 예약 같은 반복 알람도 등록할 수 있습니다.

완료 기록

한 일 저장 · 주간 · 월간 정리

체크한 할일은 archive에 날짜별로 자동 저장됩니다. ⚙ 기간별 보기에서 주간 · 월간 · 분기 · 반기 · 년 단위로 모아 보고, 복사하거나 파일로 저장할 수 있습니다.

  • 매일 완료 항목 → JSON + Markdown 기록
  • 「오늘 한일 정리하기」로 당일 요약
  • 주 시작 요일 선택 (월~일)
  • 회고 · 보고용 텍스트 바로 복사

Mac ↔ Google Cloud ↔ Windows

Google 로그인 동기화

어디서든 같은 메모

집 Mac에서 쓰다가 회사 Windows에서 이어 쓰기 — Google 계정 하나면 됩니다. 메모 · 섹션 · 할일 목록이 클라우드에 저장되고, 불러오기 · 지금 동기화 · 3시간마다 자동 sync로 맞춰집니다.

  • Mac ↔ Windows 크로스 플랫폼
  • 새 기기: 업로드 후 선택적 불러오기
  • 메모별 archive도 함께 sync
  • 동기화 키 없이 Google 로그인만

캘린더 일정 추가 버튼 · 자동 추가 시 import와 export가 함께 동작합니다.

  • 타이틀바 핀 — 창을 항상 맨 위에 고정
  • 드래그앤드롭으로 오늘 할일 ↔ 섹션 이동
  • 자정(KST) 지나면 미완료 항목 자동 정리
  • 완료 기록 archive · ⚙ 기간별 보기
  • 메모 색상 슬라이더 · 자동 줄바꿈 · 로그인 시 자동 실행

Mac 설치 · 실행 안 될 때
  1. zip 완전히 압축 해제 (미리보기 안에서 바로 실행 X)
  2. Memos.app → Applications로 이동
  3. 안 열리면: xattr -cr /Applications/Memos.app && open /Applications/Memos.app
