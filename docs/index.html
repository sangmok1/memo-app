오늘 할일 · 커스텀 섹션

오늘 집중할 일은 상단에 고정. 할일 외에 개인 메모 등 섹션을 추가하고, 핀으로 위치를 고정하거나 드래그로 순서를 바꿉니다.

Google 로그인 동기화

계정 하나로 메모를 클라우드에 저장. 불러오기 · 지금 동기화 · 3시간마다 자동 sync. Mac과 Windows 사이에서도 그대로 이어집니다.

1회성 · 주기적 알람

메모와 별도 알람 보드. 시간이 되면 화면 중앙에 크게 알림. 물 마시기, 병원 예약 같은 반복 알람도 등록할 수 있습니다.

Google 캘린더 양방향

캘린더 → 메모 팀 미팅 14:00 [캘린더]

오늘 일정을 오늘 할일에 자동 반영

메모 → 캘린더 [보고] 주간 정리 (15:30)

형식에 맞으면 Google Calendar에 일정 생성

캘린더 일정 추가 버튼 · 자동 추가 시 import와 export가 함께 동작합니다.

  • 타이틀바 핀 — 창을 항상 맨 위에 고정
  • 드래그앤드롭으로 오늘 할일 ↔ 섹션 이동
  • 자정(KST) 지나면 미완료 항목 자동 정리
  • 완료 기록 archive · 기간별 보기
  • 메모 색상 · 자동 줄바꿈 · 로그인 시 자동 실행

Mac 설치 · 실행 안 될 때
  1. zip 완전히 압축 해제 (미리보기 안에서 바로 실행 X)
  2. Memos.app → Applications로 이동
  3. 안 열리면: xattr -cr /Applications/Memos.app && open /Applications/Memos.app
