최종 업데이트: 2026-09-21 · Memos (memo-postit)

Memos("본 앱")는 바탕화면 할일 메모 데스크톱 앱입니다. 본 방침은 본 앱이 수집·이용·보관하는 정보를 설명합니다.

1. 수집하는 정보

  • Google 계정 정보 (이메일, 이름, 프로필 식별자): Google 로그인으로 동기화를 사용할 때, 사용자를 식별하고 기기 간 데이터를 연결하기 위해 사용합니다.
  • 메모·할일 데이터: 사용자가 앱에 작성한 메모, 할일, 완료 기록. 동기화 사용 시 클라우드에 저장됩니다.
  • Google 캘린더 데이터 (선택): 사용자가 캘린더 연동을 켠 경우에 한해, 일정을 앱에 가져오거나 추가하기 위해 캘린더 읽기/쓰기 권한을 사용합니다.

2. 정보의 이용 목적

  • 여러 기기 간 메모·할일 동기화
  • Google 캘린더 일정 가져오기/추가 (사용자가 해당 기능을 켠 경우)
  • 로그인 및 사용자별 데이터 식별

본 앱은 위 목적 외로 데이터를 사용하지 않으며, 광고·추적·프로파일링에 사용하지 않습니다.

3. 저장 및 보안

  • 동기화 데이터는 사용자 본인 Google 계정 단위로 앱 운영자의 Google Cloud Storage에 저장되며, 계정별로 분리됩니다.
  • Google 인증은 표준 OAuth 2.0으로 처리되며, 앱은 사용자의 비밀번호를 저장하지 않습니다.

4. 제3자 제공

본 앱은 수집한 데이터를 제3자에게 판매·공유하지 않습니다. 데이터 저장을 위해 Google Cloud(Google LLC) 인프라를 이용하며, Google의 데이터 처리 약관이 적용됩니다.

5. 데이터 보관 및 삭제

  • 사용자는 앱 내에서 메모를 삭제할 수 있으며, 삭제한 항목은 휴지통에서 3일간 보관 후 영구 삭제됩니다.
  • 동기화 데이터 삭제 또는 계정 연동 해제를 원하시면 아래 연락처로 요청하실 수 있습니다.

6. Google API 데이터 사용 (Limited Use)

본 앱의 Google 사용자 데이터 이용은 Google API Services User Data Policy(Limited Use 요건 포함)를 준수합니다. 캘린더 등 Google 사용자 데이터는 위에 명시한 기능 제공 목적으로만 사용됩니다.
